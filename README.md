# 🚀 Flask SQL Pandas ML App

A complete beginner-friendly project that integrates **Flask**, **SQL**, **Pandas**, and a **Machine Learning model** to build a simple data-driven web application.

---

## 📌 Project Overview

This project demonstrates how to:

* Build a backend using Flask
* Work with structured data using Pandas
* Integrate a trained Machine Learning model (`lr_model.pkl`)
* Handle data flow between application and model
* Prepare a scalable data pipeline

---

## 🛠️ Tech Stack

* **Python**
* **Flask**
* **Pandas**
* **NumPy**
* **Scikit-learn**
* **SQL (via Python integration)**

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```
git clone https://github.com/sourabhbagda24/flask-sql-pandas.git
cd flask-sql-pandas
```

---

### 2️⃣ Create Virtual Environment

```
python -m venv venv
source venv/bin/activate     # Mac/Linux
venv\Scripts\activate        # Windows
```

---

### 3️⃣ Install Dependencies

```
pip install -r requirements.txt
```

---

### 4️⃣ Run the Application

```
python app.py
```
